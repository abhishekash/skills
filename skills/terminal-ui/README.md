# Terminal UI

The featured layer: four skills that cover the whole terminal-cockpit loop.

| Skill | Role |
|---|---|
| [terminal-cockpit-design](terminal-cockpit-design/SKILL.md) | Design the information hierarchy, status language, responsive layout, and interaction model. |
| [textual-tui-engineering](textual-tui-engineering/SKILL.md) | Implement it in Textual without losing selection, evidence, or shutdown safety. |
| [tui-regression-testing](tui-regression-testing/SKILL.md) | Prove the core flow still works at real terminal sizes. |
| [terminal-demo-media](terminal-demo-media/SKILL.md) | Record an honest, legible demo of the real UI. |

Start with the design skill, then build, test, and show.
